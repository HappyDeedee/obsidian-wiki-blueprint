# Wiki 查询

公开版 0.2.2。读目标库现行规则及 [查询方法](../../docs/06-query.md)，时间/类型见 [数据模型](../../docs/02-vault-model.md)。不绑定作者服务器。

- 使用 reader；默认不写正文、日志、状态或阅读队列。不因持 curator 密钥而越权。
- 先读 20-Wiki/别名表.md 定位同义说法（派生视图，由程序从主题页 aliases 生成，勿手工维护；不存在时按 [数据模型](../../docs/02-vault-model.md) 的别名节处理，并在回答中说明覆盖范围）。全景才读索引/总览。已核别名→20-Wiki实体/人物/概念/综合→30-Projects→引用原文；问会议/自述直接查对应完整原文。
- 每次限定目录、一两个词，跟分页与 revision；搜索仅定位，回读相关正文，范围不足明确说明。未命中不证明不存在。
- 数字、单位、门槛、日期、编号、对象及条件逐项配最短必要逐字引文与完整路径；不抄助手历史答案。纪要不替代完整转写。
- 区分已发生/计划/假设/未核实、当前/历史及适用范围。created/updated 不是 event_date/source_date，缺年不补；复核日不等于失效。
- 术语候选/外部草案不是私人事实；自动声纹不是人工身份确认。只有原件未读就说明缺口，写作范本不作事实证据。
- 问运行时核状态生成时间，不把旧日志当实时。00-Test、生成物不参与普通事实回答。
- 别名表是程序生成物，知识索引/总览是派生导航；本 PR 尚未提供后二者的统一生成入口（见 [运维手册](../../system/runbooks/08-operations.md) 的"程序化维护任务"节），不是第二份手工真相；缺失或过期时如实说明检索覆盖范围，不编造别名。
- 先回答，再给依据与未查范围。records 模式返回 records/scope/coverage/unresolved，不强迫普通用户看数据表。
- 仅在明确保存授权下使用 proposer 新建 Inbox/问答投稿，保留实际引用与 user_confirmed:false；回读返回路径。不能直接正式入库，AI 答案不成为独立事实。
- 确认中心收到答复不等于已采纳；只认对应答复的最终提交回执与知识页。
