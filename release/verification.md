# 公开版验收范围

发行目标 `0.2.0`，记录日期 **2026-10-29**。本仓库交付可运行的本地参考版和 AI 辅助搭建整套系统的源码/说明；不把源码存在等同于生产部署完成。

## 本地已验证

- Windows / Python 3.12：47 项参考程序测试，45 通过、2 项因当前账号不能创建符号链接而跳过。包含新目录安装、投稿/正式回执区别、幂等、角色限制、CSRF/Origin、版本冲突、备份恢复和未知事实保留。
- 会议接收器：12 项测试全部通过；SDK/识别响应使用夹具，覆盖任务持久化、音频 hash 去重、结果/导出重试、不确定提交不重复收费、缺产物拒绝完成和访问控制。没有调用收费转写服务。
- Node 时间/整理规则：原生产规则夹具 40 项断言通过；另有 3 项身份与只新建投稿测试通过。不能据此推断整个上游平台已集成。
- Python/JavaScript/TypeScript 源码语法检查通过；这不等同于安装全部 Linux 服务或加载全部第三方依赖。
- 实际 Edge 无头浏览器：登录、问题卡片、答复进入待核投稿、虚构发言人操作、词典页面通过，无页面脚本错误。检查桌面 1440×1000 与模拟窄屏 390×844，无横向溢出；不是实际手机验收。
- 新环境本地安装、答复、最终回执绑定及停止写入后的备份/新目录恢复有自动化检查。凭证在使用者私有目录生成，不进入页面源码或连接 URL。

## 发布检查

- 76 份业务参考源码（74 份运行源码、2 份本地备份辅助模块）、原 UI 派生页面、4 个 Skill、配置字段/安全样例、8 份搭建手册与 Agent 入口。来源清单和包清单包含 SHA256。
- 发布前检查公开白名单、相对链接、Skill 格式、文件集合与 hash；另执行 gitleaks 工作区/历史扫描和真实私人指纹对照。扫描可降低泄漏风险，不能证明任何形式的绝对无泄漏。
- GitHub Actions 将在 Ubuntu/Windows 跑参考测试及会议/Node 测试，另在独立 Ubuntu 任务中生成临时凭证并检查 CouchDB 权限和原版只读 MCP。实际托管运行和远程归档回读结果在通过后补记；配置文件存在不代表已通过。
- 本机 Docker 引擎当前不可用，因此本机没有宣称容器测试通过。容器测试不调用模型、不接作者生产库，临时卷只属于新建随机 CI 项目。

## 仍须在使用者环境完成

1. `curation_*` 自定义 MCP 宿主接线与正式多身份中间件。基础 Compose 是原版只读 MCP，无法直接替代生产扩展；具体任务见 `system/source-map.md`。
2. 真实生产确认中心的同源 Cookie/CSRF 会话适配、HTTPS、受限音频路由。公开本地 UI 已使用该协议；旧生产参考认证入口不等同于适配完成。
3. 自己的听悟账号/模型、真实授权录音、声纹识别、人物更名/撤销、正式纪要回写和模型语义验收。声纹库、音频、模型、私人正文、确认历史和生产账号均不发布。
4. 实际手机与电脑的 LiveSync 双向文本/附件 hash、E2EE、离线重连与冲突验收。浏览器窄屏和数据库健康都不能代替。
5. 自己的 Agent 平台、任务 ID、权限、预算、单写控制器及备份恢复演练。Windows/macOS 不应直接执行含 Linux/systemd/fcntl 的生产脚本。

**L0 本地闭环成功，不代表 L1 多端同步、L2 自动整理或 L3 真实会议/声纹系统已全部完成。整套生产系统尚不是无配置一键安装版。**

## 原私人系统核对

此次发布前后只读核对规则、本地/部署/共享 Skill、Bot 指令、任务、看板、权限与运行清单。发现既有版本/hash 差异及个别不可读取项；没有借此次开源覆盖作者生产配置。公开版验收与原私人系统同步验收分开报告。具体私人记录留在作者私有部署目录，不发布原始账号、路径和配置。
