## 未关闭的生产复建差距

| 差距 | 原因与后续验收 |
| --- | --- |
| 自定义 MCP 宿主 | 模块仍需注册实际 schema、注入 Vault/队列/持久存储、挂权限和恢复逻辑，详见 source-map |

| 多端同步 | 基础容器与只读工具已有独立测试；每台真手机的 LiveSync、加密和附件读回尚须验证 |
| 听悟 | 需自己的账户和真实短录音验证云端权限、签名拉取及结果覆盖；本次没有发起付费转写 |
| 声纹/人物 | 依赖、模型路径、统一配置加载及身份/领域授权需安装；人物日期规则需要修正后启用 |
| 平台与服务安装 | 控制器依赖平台内部接口，服务清单不等于完整安装器；自己的版本、ID、任务和开关需逐一接线 |
| 权限承诺 | 生产宿主必须额外拒绝原件写删与系统规则修改；仅阅读 Skill 或加载角色合同不构成强制隔离 |

所以：新 AI 已有更完整、可发现的配置与搭建材料，并能离线执行新增配置和转换入口；仍不能把“读完仓库”直接等同于“整套生产系统一键等效运行”。
