# 已确认词典

这是新安装的空白模板。只有所有者明确确认、并附来源和确认日期的条目，才能加入正式词典。不要把演示词语或模型推测当作已确认事实。

```json
{"schema":1,"entries":[],"unknowns":[]}
```

在自己的知识库中把这份模板保存为 `20-Wiki/综合/已确认词典.md`。该页面是唯一正本；网页、会议和巡检服务读取它的缓存，不另建一份独立词典。

## 词典是怎样长出来的

- 新库从空词典开始：ingest/health 在词典为空时跳过"先读词典"步骤，并在报告中注明词典尚未启用；"无词典"不等于"无术语"，术语问题仍按原文核实。
- 只有所有者明确确认、并附来源和确认日期的条目，才能加入正式词典；更新由指定维护身份在明确授权下执行，版本递增。演示词语、模型推测、外部通用定义不直接入库；外部通用定义与私人用法分开记录。
- 明确错写只在派生知识中纠正并保留原话，不改写原文。热词库只影响新的识别任务，不改写已确认条目；未知识别结果受保护，不自动入库。
- 词典条目是拼写和释义依据，不是本场事件证明；不得据词典推定人物身份、事件发生或能力上线。
