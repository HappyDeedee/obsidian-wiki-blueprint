# 整套系统公开发行：范围与执行顺序

目标：让新的 AI 仅凭本仓库，协助使用者在自己的设备与服务器建立来源可追溯、可确认、可巡检、可持续更新的多端 Wiki。

## 本次范围

1. 依据实际程序和配置，梳理桌面/手机、同步中继、知识库接口、会议处理、声纹库、确认中心、整理与巡检的连接关系。
2. 把私有地址、账号、密钥、人员和资料替换为使用者自己的配置；第三方软件保持原许可。
3. 发布确认中心的可复用界面，以及有明确能力边界的本地启动程序。
4. 发布服务配置样例、平台搭建步骤、Agent 读取顺序、数据合同与逐阶段验收清单。
5. 测试空环境、隐私扫描和公开仓库内容；分开报告本地测试、服务器测试及真实手机验收。

## 不能混为一谈

- 可启动网页不等于生产系统已复制。
- 文件同步不等于 Agent 已读完、理解并核验知识。
- 相同界面不等于声纹模型、听写服务或 Agent 平台已部署。
- 示例配置不能包含作者的生产连接，使用者须提供自己的服务与授权。
- 新环境的初始化不能对已有知识库运行重置、清空或覆盖操作。

本文先确定交付范围；各组件的实际实现与验收状态，以仓库状态和功能对照为准。
