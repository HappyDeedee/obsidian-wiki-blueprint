## 参考程序的明确限制

- 可信本地用户、单进程写入协作模型；不是网络安全边界。
- mkdir 锁无自动抢占；意外崩溃后需确认所有写入者已退出，再人工移走锁并沿 journal 恢复。
- journal 能恢复逐文件提交，不保证多文件对外瞬间原子可见；同步器/外部编辑不遵守本锁，必须额外隔离。
- 不证明 Agent 真的读完；不自动生成知识；不校验完整 YAML 或语义事实。
- health 只做有限目录/链接候选/回执检查，不能冒称 Obsidian 完整解析或全库语义 lint。
- question/answer 的现场来源由操作者核实，没有登录系统，不能证明远端答复者身份。
- demo 是预先写好的虚构提案与答复，用于验证机制，不是模型效果测试。

搭建者需要完整生产版时，让 Agent 按 docs/00 分阶段补齐这些能力。**缺一项就如实列待实现，不用作者连接、不偷换成已经具备。**
