## 本地参考的边界

- 文件 Wiki 用于可信本机和协作式单写入；网页密码只保护本机 HTTP 入口，不提供远程角色隔离或跨同步锁。
- mkdir 锁不抢占；崩溃后先确认所有写入者退出，再沿原 journal 恢复。逐文件 journal 不保证多文件瞬时原子可见。
- 示例是预写虚构提案/答复；不自动生成知识，不证明模型理解、完整 YAML/Obsidian 解析或全库语义。
- 网页会话说明本机密码持有者提交了答复；可信 CLI 操作者仍可改文件，不作为跨用户取证系统。
- 发言人卡只存演示交互，不训练声纹、不写人物页。生产参考与公开 UI 会话方式不同，必须适配。

接手 AI 按 [源码地图](../system/source-map.md) 补宿主与平台差异，按 [搭建检查表](../system/INSTALL-CHECKLIST.md) 分级报告 L0–L3。测试过什么就写什么；源码存在不等于完整生产一键完成。
